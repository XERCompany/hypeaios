# HPF — HypeAIFont binary format, v1

HPF is the native bitmap font format of HypeAI OS. Fonts are produced
host-side by `tools/fontc.py` from a PSF2 source, embedded into `kernel.bin`
as a generated `.cc` byte array, and parsed at runtime by the kernel font
loader (ticket #6). The same parser must work unchanged when fonts are later
loaded from a filesystem.

All integers are little-endian. All offsets are absolute byte offsets from
the start of the file.

## File layout

```
+----------------------+
| Header (48 bytes)    |
+----------------------+
| Glyph record table   |  glyph_count x 14 bytes, sorted by codepoint
+----------------------+
| Packed 1bpp bitmaps  |  referenced by record.data_offset
+----------------------+
```

## Header (48 bytes)

| Offset | Size | Field             | Description                                        |
|--------|------|-------------------|----------------------------------------------------|
| 0      | 4    | magic             | ASCII `"HPF1"` (0x48 0x50 0x46 0x31)               |
| 4      | 2    | version           | u16, format version. Must be `1`.                  |
| 6      | 2    | flags             | u16 bitmask, see below.                            |
| 8      | 32   | name              | Face name, ASCII, NUL-padded, max 31 chars + NUL.  |
| 40     | 1    | height            | u8, face line height in pixels.                    |
| 41     | 1    | baseline          | u8, row index of the baseline (from bitmap top).   |
| 42     | 1    | default_advance   | u8, fallback horizontal advance in pixels.         |
| 43     | 1    | reserved          | u8, must be 0.                                     |
| 44     | 4    | glyph_count       | u32, number of glyph records.                      |

### Flags

| Bit  | Name                  | Meaning                                        |
|------|-----------------------|------------------------------------------------|
| 0    | `HPF_FLAG_MONOSPACED` | All glyphs share one width and advance.        |
| 1–15 | reserved              | Must be 0; parsers must ignore unknown bits.   |

## Glyph record (14 bytes, fixed size)

Immediately after the header, `glyph_count` records **sorted by strictly
ascending codepoint** — lookup is a binary search.

| Offset | Size | Field        | Description                                          |
|--------|------|--------------|------------------------------------------------------|
| 0      | 4    | codepoint    | u32 Unicode codepoint.                               |
| 4      | 4    | data_offset  | u32 absolute offset of this glyph's bitmap.          |
| 8      | 1    | width        | u8 bitmap width in pixels.                           |
| 9      | 1    | height       | u8 bitmap height in rows (usually = face height).    |
| 10     | 1    | advance      | i8 horizontal advance in pixels (clamped to ±127).   |
| 11     | 1    | bearing_x    | i8 left-side bearing: bitmap left edge vs pen x.     |
| 12     | 1    | bearing_y    | i8 distance from baseline up to bitmap top row.      |
| 13     | 1    | reserved     | u8, must be 0.                                       |

Several records may share one `data_offset` (identical bitmaps are stored
once).

## Bitmap data

1 bit per pixel, **MSB-first** (bit 7 of a byte = leftmost of its 8 pixels).
Each row is byte-aligned: row stride = `ceil(width / 8)` bytes, so a glyph
occupies `stride * height` consecutive bytes starting at `data_offset`.
Rows are stored top-to-bottom. This matches PSF2's own layout, so converted
glyphs copy through unchanged.

## C reference structs

```c
struct [[gnu::packed]] HpfHeader {
    char     magic[4];          // "HPF1"
    u16      version;
    u16      flags;
    char     name[32];
    u8       height;
    u8       baseline;
    u8       default_advance;
    u8       reserved;
    u32      glyph_count;
};
static_assert(sizeof(HpfHeader) == 48);

struct [[gnu::packed]] HpfGlyphRecord {
    u32 codepoint;
    u32 data_offset;
    u8  width;
    u8  height;
    i8  advance;
    i8  bearing_x;
    i8  bearing_y;
    u8  reserved;
};
static_assert(sizeof(HpfGlyphRecord) == 14);
```

## Vendored source font

`tools/fonts/hypeai-8x16.psfu` is a PSF2 font (8x16, 95 printable ASCII
glyphs, with a Unicode table). It is generated by fontc itself:

```bash
python3 tools/fontc.py --emit-psf2 tools/fonts/hypeai-8x16.psfu
```

**Provenance**: glyph shapes come from Daniel Hepper's `font8x8`
(<https://github.com/dhepper/font8x8>, Public Domain, itself based on IBM's
public-domain VGA font). Each 8x8 glyph is vertically doubled (every row
emitted twice) to produce a legible 8x16 cell face; baseline heuristic is
`height - height/8` = 14. `tools/fontc.py --selftest` regenerates the font
in memory and asserts the vendored file matches byte-for-byte.
