# Platform + desktop shell (P15)

Landed 2026-11-28 on `devin/hypeai-font-ui`: platform tickets #96-#98 plus the desktop-shell set (#94, #95, deskbar/tray/power). Shell research: `docs/research/desktop-shell.md` (`aad7502`).

## Platform

- **HPET + TSC + unified uptime** (#97, `44d3ac7`, merge `141f073`): `kernel/time/hpet.cc` ACPI-HPET MMIO counter; `arch/x86/tsc.cc` rdtsc calibrated vs HPET (20 ms) / PIT ch2 one-shot / PIT ticks (`tsc khz=`); `kernel/time/timer.cc` `time_now_ns()/uptime_ns()/uptime_ms()` picking tsc > hpet > pit (`time src=`); new runtime stage `time.timer` (pri 55); `klog::set_timestamps` opt-in `T+ms` prefix.
- **LAPIC + IOAPIC replace the 8259 PIC** (#96, `2062c4c`, merge `a256252`): `arch/x86/apic.cc` — xAPIC MMIO from MADT (IA32_APIC_BASE, SVR 0xFF, TPR=0), LVT timer periodic on vector 32 calibrated against the still-running PIT, IOAPIC IOREDTBL routes legacy IRQs to vectors 32-47 honoring MADT ISO polarity/trigger. PIC is masked only after the IOAPIC proves live; any failure restores PIC masks and the legacy path keeps running (`apic fallback=pic`, `apic lapic=ok io=ok`). `idt.cc` single EOI helper + `irq_enable` so IRQ1/IRQ12 handlers work identically on both paths.
- **virtio-net + ARP/IPv4/ICMP/UDP/DHCP** (#98, `c07cff0`, merge `9b74d88`): `kernel/net/virtio_net.cc` legacy I/O-port transport (1AF4:1000/1041), split vrings on contiguous PMM pages, pre-posted 2048B RX, no offloads; `net.cc` Ethernet + ARP (8-entry cache, sync resolve), IPv4 + ICMP echo reply, UDP sockets-lite, DHCP discover/ack; `net_poll()` pumped from the idle loop; `virtio-net dev=absent` never hangs boot. Markers `dhcp ip=`, `arp rx=N`, `net stack=ok`.

## Desktop shell

- **Taskbar + Start menu + tray** (`4e68cf3`, merge `860cbe6`): `kernel/ui/deskbar.cc` 36px bottom bar — Start button popup lists registered .hxer apps (sorted, launches via `desk_open_app`); middle task buttons focus/raise or minimize when focused; tray speaker/signal glyphs + RTC HH:MM clock. Damage-aware: `deskbar_idle` invalidates only changed bar cells. `winman` gains `WinState::Minimized` + `wm_set_minimized`. Markers `start menu=open/close`, `tray clock=HH:MM`.
- **Desktop icons + context menus** (#95, `81ef0e9`): `kernel/win/deskicons.cc` column-major 96x88 grid seeded from `hxrt_list()` + `HYPEOS://U/` files; 48px monogram glyphs, double-press (<500 ms) launches; generic `WmCtxItem` menus on the shared OverlayHost — window-frame system menu, icon menu (Open/Rename/Delete/Properties; builtin .hxer apps undeletable), desktop menu (Open Apps/Refresh/Change Wallpaper/Properties). Markers `icons grid=`, `icon sel=`, `desk props=ok`.
- **Caption buttons, maximize, Aero Snap, Alt-Tab** (#94, `264afa1`, merge `95da2fb`): titlebar `_`/square/`X` hit boxes (30x24, hot-tracked); maximize and snap as orthogonal flags with per-window restore rects (work area = screen minus deskbar); drag a maximized/snapped titlebar → restores floating frame under cursor; snap zones 16px edges + 32px corners (halves/quarters/top=maximize) with translucent accent preview; Alt-Tab MRU chip switcher via `subscribe_keys`. Markers `snap zone=`, `win maximized=0/1`, `alttab open=1`.
- **Tray quick-settings + toasts** (`ddaef94`): 300x220 flyout anchored above the bar — volume slider drives pullmix master gain (Q8), brightness stub, Network row shows `net_ip()`/DHCP state, Lock/Power rows; `deskbar_notify()` pushes ToastHost cards, bell glyph shows unread badge; toast slide-in ~8 paint frames. Markers `tray qs=open/close`, `qs vol=N`, `toast push=`, `tray unread=N`.
- **Lock screen + power dialog** (`9c5e3ea`, merge `43b8824`): `SessionState::Locked` (Win+L / Ctrl+Alt+L) — `session/lockscr.cc` dark veil with RTC clock, pointer gated in `hypeptr`, keys gated in `wm_key_event`; power dialog (Ctrl+Alt+Del / End) on the shared `wm_ctx` machinery; `kernel/power.cc` shutdown via ACPI ports 0x604/0xB004 (cli+hlt fallback), restart via 8042 reset (triple-fault fallback). Markers `session locked=0/1`, `power dialog=open/closed`, `power action=shutdown|restart`.
